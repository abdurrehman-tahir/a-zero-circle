# A Zero Circle — Design System

## 1. Overall Visual Direction

Style:
- Clean botanical skincare aesthetic
- Soft luxury, natural, calm, trust-building
- Premium but not overly expensive
- Minimal layout with strong product/ingredient visuals
- Light, airy sections with green brand accents

Mood keywords:
- Natural
- Safe
- Gentle
- Fresh
- Transparent
- Feminine but not childish
- Premium Korean skincare inspired

Avoid:
- Harsh colors
- Heavy gradients
- Crowded product grids
- Overly clinical medical design
- “Whitening” language for A Zero Circle

---

## 2. Color Palette

### Primary Colors

Deep Forest Green  
Use for CTAs, footer accents, strong trust sections.  
Approx: `#063B16` / `#0A3519`

Botanical Green  
Use for highlights, icons, product accents.  
Approx: `#1F7A32` / `#2E8B3C`

Soft Mint Background  
Use for hero and large calm sections.  
Approx: `#EAF7EF` / `#DFF3E7`

Pale Green Circle Background  
Use behind ingredients, icons, product callouts.  
Approx: `#DCEFE3`

White  
Use for main content sections and contrast.  
Approx: `#FFFFFF`

Warm Off-White  
Use as alternate background.  
Approx: `#FAFAF5`

Charcoal Text  
Use for body text.  
Approx: `#1E1E1E`

Muted Grey Text  
Use for secondary copy.  
Approx: `#6F756F`

---

## 3. Typography System

### Heading Font Direction
Use an elegant serif font.

Good options:
- Playfair Display
- Cormorant Garamond
- Libre Baskerville
- DM Serif Display

Use for:
- Hero headline
- Section headings
- Quote section
- Brand story headlines

Style:
- Large, refined, editorial
- Slightly tight line-height
- Strong contrast between thick/thin strokes

### Body Font Direction
Use a clean sans-serif font.

Good options:
- Inter
- Manrope
- Lato
- DM Sans
- Plus Jakarta Sans

Use for:
- Paragraphs
- Navigation
- CTA buttons
- Labels
- Product notes

### Typography Scale

Hero heading:
- Desktop: 56–72px
- Mobile: 38–44px

Section heading:
- Desktop: 36–48px
- Mobile: 28–34px

Body:
- 16–18px

Small labels:
- 12–14px

CTA:
- 14–16px, medium weight

---

## 4. Layout System

### Page Width
Reference uses a centered, narrow luxury layout.

Recommended:
- Max width: 1180px–1280px
- Section padding desktop: 80px–120px vertical
- Section padding mobile: 48px–72px vertical
- Horizontal padding: 24px mobile, 48px desktop

### Layout Style
- Alternating full-width background blocks
- Hero with text left, product/visual right
- Centered quote band
- Three-column ingredient/benefit cards
- Large image-led sections
- Soft negative space
- Minimal borders

---

## 5. Navigation

Recommended nav:
- Home
- About
- Ingredient Index
- Partners
- Contact

Center or left:
- A Zero Circle logo

Right:

## 17. Icons

Use:
- Thin line icons
- Botanical or skincare-related
- Circle containers
- Minimal detail

Icon examples:
- Leaf
- Drop
- Shield/check
- Search/magnifier
- Ingredient molecule
- Heart
- Woman/family outline
- Globe/import

Avoid:
- Heavy filled icons
- Cartoonish icons
- Medical/hospital icons

---

## 18. Image Style

Use:
- Korean skincare bottles/jars/tubes
- Soft green/cream backgrounds
- Ingredient closeups
- Pakistani lifestyle imagery
- Women-led/home-business visuals
- Minimal, clean product staging

Avoid:
- Exact reference product shots
- “Whitening cream” positioning
- Exact visual layout copied from the reference

---

## 19. Visual Motifs

Use:
- Soft circles
- Floating leaves
- Ingredient illustrations
- Pale green blobs
- Clean product shadows
- Oversized background typography
- Thin line dividers

Avoid:
- Copying exact aloe visuals
- Same quote text from reference
- Same product layout details
- Same logo placement with identical spacing

---

## 20. Recommended A Zero Circle Design Direction

Final design direction:

A soft, botanical Korean skincare landing page with a premium editorial feel, using pale mint backgrounds, deep green accents, elegant serif headings, clean sans-serif body text, ingredient-focused cards, trust-building copy, women-led storytelling, and a coming-soon ingredient database section.

The site should feel:
- trustworthy
- calm
- premium
- ingredient-aware
- Pakistani-market relevant
- women-led
- skincare-educational
